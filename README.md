# ImeBench — 输入法整句正确度评测

用模拟键盘测试闭源中文输入法（微软拼音 / 搜狗 / 百度等）的**整句转换正确率**。

程序向一个内嵌的文本框逐键发送真实按键，输入法正常参与转换，上屏后与期望文本比对，输出错字率（CER）与错句率（SER）。纯黑盒，不连任何输入法内部接口。

```
码表 + 测试文章 → 编译成按键表 → 逐键模拟 → 上屏比对 → CER / SER → 导出报告
```

---

## 快速开始（五步）

**第 0 步：把输入法切到全拼。**
双拼会把 `zhongguo` 按声母韵母重新切分，输出看起来像乱码（如「脏欧能古偶」）——那不是程序错，是双拼的正常行为。测哪个输入法，就切到那个输入法的全拼模式。

1. **语料页**：加载码表（可点「新建示例」生成一份格式样例），粘贴测试文章，点「编译 →」。
   - 若弹出**待确认清单**（码表没覆盖的字 / 多音字），逐条指定编码后点「重新编译」。
2. **速度标定页**：按键串填 `zhongguo `（末尾带一个空格），期望上屏填 `中国`，点「开始标定」。
   - 标定会从快到慢找出这台机器 + 这个输入法的最快稳定间隔，推荐值（含容错）自动填入运行页。
3. **运行页**：确认状态栏全部正常（前台=本窗口、宿主焦点=有），点「▶ 开始」。
4. 测试中随时可停：**Ctrl+Alt+S** 全局热键，或点「■ 停止」，或直接切走窗口（失焦自动停止）。
5. 跑完点「导出 JSON / CSV / HTML」保存报告。

## 码表格式

每行一条映射，`#` 开头为注释：

```
中	zhong
国	guo
人	ren
，	,
```

- 分隔符为 TAB（兼容单个空格）。
- **同一字符写多行 = 一字多码**（多音字）。编译时会在待确认清单里让你逐个指定用哪个。
- 码表没覆盖的字符（OOV）也会进清单：可补码，或选择跳过——跳过的字符不计入错字统计的分母。

## 编译选项

| 选项 | 含义 |
|---|---|
| 单元键长上限 | 一个上屏单元最多多少个按键，超过就插入确认键分段上屏 |
| 标点顶屏 | 遇到标点立即上屏当前内容（符合输入法习惯） |
| 确认键 | 触发上屏的按键，默认空格 |
| 音节分隔符 | 双拼 / 五笔等需要音节分隔的方案才填（如空格），全拼留空 |

## 按键表页

编译产物是一张**可编辑的按键表**（一行 = 一个上屏单元）。特殊符号：`⏎` = 确认上屏，`␣` = 音节分隔符。改完直接生效；也可保存 / 载入 `.ikeys.json` 复用。

## 速度标定怎么做

- 每个输入法（甚至每台机器）的最快稳定速度不同：太快会丢键或失真。
- 标定按 `0→1→2→…→128ms` 从快到慢扫，每档重复 N 组**全部正确**才算通过，命中即停。
- 结果 + 容错（默认 1ms）= 推荐间隔，自动填入运行页「按键间隔」，可随时手改。
- 若某档一个输出都没有会立即中止——先检查：是否切到全拼？窗口是否在前台、焦点是否在宿主？

## 停止与断点

- **Ctrl+Alt+S**：全局热键，任何时候可停。
- **主窗口失焦即停**：测试期间切换窗口会自动停止。
- **句级断点 + 句首重入**：停止/崩溃后重开程序，点「↻ 从断点继续」，从出错那句的**句首**重打（半句丢弃，保证每句测量条件一致）。
- 自动检查点每 5 秒落盘到 `%LOCALAPPDATA%\ImeBench\checkpoint.json`。

## 统计口径

- **错字数 = 编辑距离**（Levenshtein），细分：S 替换 / D 删除 / I 插入。
- `CER = 错字数 ÷ 期望总字数`；`SER = 错句数 ÷ 上屏次数`（一次上屏与期望不完全一致即记 1 错句）。
- 每个上屏单元独立比对、独立清空，错误不跨句传播。
- 另有「自然句 SER」：按标点切分的自然句口径。

## 命令行

```
ImeBench.exe                          正常启动 GUI
ImeBench.exe --smoke <码表> <文章> [间隔ms]
                                      无人值守：编译→标定(省略间隔时)→跑完→导出
                                      报告写入 %LOCALAPPDATA%\ImeBench\smoke-report.*
ImeBench.exe --poc                    打开底层技术验证窗口（排查问题时用）
```

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 上屏全是乱码（如「脏欧能古偶」） | 输入法在双拼模式，**切回全拼** |
| 一个键都没进去 | 窗口不在前台或焦点不在宿主——看状态栏两项是否正常，把窗口点到最前面再开始 |
| 结果里混着没转换的拼音字母 | 同上，焦点丢了；程序已内置自动抢焦点，若仍出现请勿在测试期间点击其他窗口 |
| 丢字 / 整段丢失 | 间隔太快，回标定页重新标定 |
| 第二遍跑正确率变高 | 输入法学习了你的语料（动态调频/用户词典）。多轮对比请换语料，或交叉顺序跑取平均 |
| 状态栏 SendInput 不是 40B OK | 程序异常，重启程序 |

## 架构分层

```
UI (UI/)                     界面、热键注册、失焦消息的入口
  │
  ├─ 控制层 Core/Control/     RunController：统一停止入口（热键/按钮/失焦）+ 每键闸门
  │                           Runner：编排层，把三层串成"发→收→比"的循环 + 断点落盘
  ├─ 发送层 Core/Sending/     KeyPlayer：读按键表逐键发送；Pacer：精确定时；Calibrator：速度标定
  ├─ 验证层 Core/Verify/      Verifier：捕获上屏文本并比对；Scoring：Levenshtein + CER/SER
  └─ 语料层 Core/Corpus/      CodeTable：码表；Compiler：文章→按键表；KeyTable：可编辑按键表
  │
  └─ Win32/                  SendInput / 宿主控件(ImeHost) / Win32 P/Invoke
```

依赖方向自上而下：UI → 各层 → Win32。层与层之间不互相回调；验证层只依赖 `IUpTextSink` 接口，将来换 TSF sink 或外部窗口捕获时，上层无需改动。

