# ImeEval 样例码表（小鹤双拼）
# 格式：字符或词组<TAB>按键串
# 同一左列多行 = 一字多码（多音字），编译时自动取首码
# 左列 2 字及以上 = 词组，编译时最长优先匹配，命中即整词一次输入
#
# 按键串语法（详见 README）：
#   _           空格（真实的空格字符会被忽略）
#   <Shift>     特殊键：<Enter> <Backspace> <Del> <F1> <Up> <Esc> ...
#   {DELAY=100} 在此等待 100 毫秒
#
# 示例：中国人民万岁 → 中国|人民|万岁 → vsgorfmbwjsv（小鹤双拼）
中	vs
国	go
人	rf
民	mb
万	wj
岁	sv
# 以下为词组：命中后整词一次输入（可在语料页用「词组优先」开关对比）
中国	vsgo
人民	rfmb
万岁	wjsv
，	,
。	.
